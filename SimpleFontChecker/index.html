Help

  • Select View: Switch between Character List, Preview, and Help.
  • Preview View: Choose between font block and scrollers in the Preview tab.
  • PNG File: Load a font sprite sheet in PNG format.
  • Zoom: Scale the Character List and ticker tiles.
  • Start Scroller: Toggle the ticker animation when Preview is set to scrollers.
  • Frame: Outer padding of the sprite sheet before tiles start.
  • Gap: Spacing between tiles inside the sprite sheet.
  • Canvas Width/Height: Size of the random preview canvas.
  • Grid Width/Height: Size of a single tile in pixels.
  • Tile Limit: Limit how many tiles are shown/used (0 = no limit).
  • Ignore Chars: Comma-separated tile indices to skip.
  • Save/Load Settings: Store or restore your current setup.
  • Selection: Drag on the source image to define a tile, drag the green tile to move it, resize it from any side, and drag red or blue strips to adjust frame and gap offsets.
  • Green Overlay: The green rectangle is the active tile area. Drag inside it to move the current tile origin.
  • Resize Handles: Use the small green handles on the edges and corners to resize the tile area from any side.
  • Red Overlays: Red strips represent frame offsets. Each side can be dragged directly when its frame value is greater than 0.
  • Blue Overlays: Blue strips represent gap offsets. Each side can be dragged directly when its gap value is greater than 0.
  • Hover Hints: Hover over red or blue strips to get a short description of what that helper controls.
  • Zoomed Inspection: In zoomed mode the inspector stays full size and the page can scroll so you can inspect larger sprite sheets precisely.
